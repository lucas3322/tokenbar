Os números

Metade é exata.
A outra avisa que não é.

O Codex grava o percentual real do limite, vindo do servidor. O Claude Code não — por isso o percentual dele é calculado, e vem marcado com ✨ no painel.

Codex

Exato.

O percentual das janelas de 5h e semanal vem do servidor, gravado pelo próprio Codex. O TokenBar só lê.

  • Percentual do limiteexato
  • Janela e horário de resetexato
  • Tokens e custoexato
  • Precisa configurarnão

Claude Code

Calculado ✨

O limite só aparece quando a API já recusou. O app converte o consumo em custo e compara com um teto que se corrige sozinho, sem nunca passar de 100%.

  • Percentual do limiteestimado ✨
  • Janela e horário de resetexato
  • Tokens e custoexato
  • Precisa configuraropcional, uma vez

O teto aprende

Se uma janela passou do teto sem recusa, o limite era maior e o teto sobe. Uma recusa real marca o ponto exato.

Acertar leva cinco segundos

Digite nos Ajustes o percentual que o app oficial da Anthropic mostra e o teto se ajusta na hora.

Instalar

Três passos,
uma vez só.

Requer macOS 14 ou superior e um Mac com Apple Silicon (M1 em diante). Mostra dados de quem usa Claude Code ou Codex na própria máquina.

Baixe e descompacte

Arraste o TokenBar.app para a pasta Aplicativos.

Baixar para Mac

Libere a primeira abertura

O app não é assinado por conta paga da Apple, então o macOS bloqueia na primeira vez. Isso destrava de uma vez por todas:

xattr -dr com.apple.quarantine /Applications/TokenBar.app

Sem terminal: botão direito no app › Abrir › Abrir.

Acerte o Claude

Opcional. Em Ajustes › Acertar o Claude, informe o percentual que o app da Anthropic mostra em Configurações › Uso. O Codex já vem certo.
